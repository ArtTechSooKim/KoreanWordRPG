# Korean Word RPG 기획 (GDD)

> 결정 사항과 Claude 안(사용자 확인 전)을 나눠 적는다. 영단어RPG의 게임 규칙(전투·필드·성유물·세이브)은 `Docs/영단어RPG/GDD.md`를 그대로 물려받는다.

## 1. 한 줄

영단어RPG를 거꾸로: 한국어를 배우는 외국인이 **게임하다 보니 한국어 단어를 외우는** RPG. 전투에서 기술을 쓸 때마다 한국어 단어 문제를 푼다.

## 2. 사용자 결정 (2026-11-20)

- 영단어RPG의 파생 게임으로 **따로 출시** — "외국인 대상 한국어RPG는 바로 출시할 수 있을 것 같다", 새 저장소
- 저장소 = **공개** (영단어RPG와 같음 — Mac 빌드 서버 무료), 이름 = **Korean Word RPG** (저장소 KoreanWordRPG)
- 화면 글 = **영어 먼저**, 다른 언어는 출시 뒤 더할 수 있게
- **판매 = 처음부터 유료 1,000원** (처음엔 '앞 지역 무료 + 정식판'을 골랐다가 정정) — 인앱 결제·무료 구간 없음
  - Claude 메모: 사 보기 전에 해 볼 수 없으니 스토어 스크린샷·미리보기 영상(실제 문제 화면)이 중요. 다른 나라 가격은 애플이 1,000원에 맞춰 정함. 구글플레이 유료 앱은 판매자 계정 필요

## 4. 화면 글 (Claude 안)

- 글을 코드에 흩어 두지 않고 **글 표 한곳**(키 → 영어)에 모음 → 나중에 일본어·스페인어 등을 표에 칸만 더해 넣을 수 있게
- 먼저 영어 한 언어. 한국어 조사 도우미(WithJosa)는 영어 글에선 필요 없음 — 영어의 a/an·복수형만 조심
- 영어가 한국어보다 길어 버튼·알약·이름표에 넘치기 쉬움 → 화면마다 캡처로 확인
- 글꼴: 본문 Noto Sans KR·제목 Jua 모두 영어 글자가 있음 (한국어 단어도 같은 글꼴로)

## 5. 단어 (#2에서 만듦 — 사용자 검수 전)

- 출처: 국립국어원 「한국어 학습용 어휘 목록」(2003) — 5,965개, A(초급)·B(중급)·C(고급). 자료실 원문 표시 = 공공누리 제1유형(출처 표시하면 상업 이용·변형 가능, 2026-11-20 확인). LICENSE에 출처 · 앱 안 출처는 출시 전에
- **고른 방법** (#2): 이야기를 그대로 쓰므로(사용자 결정), 영단어RPG '누군가의 기록'의 한국어 문장(검수본)마다 그 줄에 나오는 단어를 하나씩 골라 그 줄을 예문으로, 영어 원문을 해석으로.
  초원·서고 150 = 일기 150줄(초급 119 · 중급 31) · 숲·정글·동굴 300 = 생존일지 290줄 + 기록 밖 10개(초급 99 · 중급 154 · 고급 39 · 목록 밖 8 — 괴물·악마·조약·공화국·백만·사막·증인·사원(절))
  → 처음 배우는 사람에게 쓸모 있는 말이 많이 들어감 (기본형 동사·형용사·명사). 동음이의어는 목록 풀이로 그 줄의 뜻을 고름 (다리 = 교량, 달리다 = 뛰다)
- 영단어RPG와 같은 크기: 초원·서고 150 · 숲·정글·동굴 300 (tier1·tier2 자리). 다음 지역 단어는 목록의 남은 단어에서 (새 이야기 줄과 같이)
- 목록의 '풀이'는 한국어 설명뿐 → 영어 뜻·예문(한국어 + 영어 번역)은 Claude가 쓰고 사용자 검수 (영단어RPG 단어 검수 페이지와 같은 방식)
- 같은 영어 뜻 두 번 금지 (보기가 같아짐), 동음이의어는 한 뜻만 (예: 배 = ship / pear / belly 중 하나 — 등급표의 풀이로 고름)

## 7. 사용자 결정 (2026-11-20, 두 번째)

- **이야기 = 영단어RPG 이야기를 영어로 옮겨 그대로** ('말을 잃어 가는 세계' — 지역·몬스터·인물·보스 대사·입장 영상 자막·누군가의 기록 모두 영어로)
- **로마자 보여 줌**: 한국어 단어 아래에 로마자 (예: 사과 → sagwa). 기준 = 「국어의 로마자 표기법」(문화체육관광부 고시) — 글자대로가 아니라 **소리 나는 대로**
  (예: 학교 hakgyo, 신라 Silla, 같이 gachi). Claude 안: 단어 CSV에 로마자 칸을 두고 Claude가 쓰고 사용자 검수 (규칙만으로 자동 변환하면 소리 바뀜을 틀리기 쉬움).
  문제·뜻 카드·도감·사전에서 단어 아래 작은 글씨로
- **단어장 고르기 화면 끔** — 모두 기본 단어장(영단어RPG의 '수능' 자리 = 이 게임의 한국어 단어장)으로 시작. 비즈니스·의학 단어장은 이 게임에서 쓰지 않음
- **발음 듣기 안 넣음**
- **정식판 특전 없앰** (호기심 물약·특제 상처약 선물 — 유료 앱이라 따로 살 것이 없음)
- **크리스마스 선물 퀴즈 = 한국어 크리스마스 단어로** (영단어RPG의 영어 28개 대신. 선물·편지 흐름은 그대로, 편지 글은 사용자가 영어로 새로 쓰거나 옮김을 확인)
