대화 기록이 이어지지 않으므로 Figma 노드 id·캡처 방법·외부 도구 사용법 같은 작업 메모를 여기에 남긴다.

## 한국어 단어장 검수 페이지 (#2)

- 주소: https://claude.ai/artifact/BoUstQ3SNDG2R5Fo1x4jzP (지금은 사용자만 열 수 있음 — 다른 검수자는 페이지의 공유 메뉴로)
- 기능: db + user(profile). 메모 = `notes/{wordId}` {book(tier1·tier2), word, meaning, roman, suggestion(새 영어 뜻), romanSuggestion(새 로마자), remove, memo, by(적은 사람 id), updatedAt} ·
  묶음 다 봤음 = `sections/{tier1_1~2·tier2_1~3}` {done}. 읽기 = ArtifactData list notes → picks 파일에 반영 → build_books.py --write → gen_review.py → 같은 주소로 다시 올림
- 페이지 원본 = `Tools/korean_words/review_template.html` (+ gen_review.py가 단어를 넣음 → Builds/, 깃 밖)
