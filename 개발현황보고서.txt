[2026-11-20] #10 크리스마스 선물 퀴즈를 한국어 단어로

   동사 4: 축하하다 · 꾸미다 · 포장하다 · 반짝이다 / 형용사 4: 따뜻하다 · 춥다 · 즐겁다(merry, joyful) · 고요하다(silent, calm — '고요한 밤')

[2026-11-20] #7 단어: 전 → 이전 (사용자)
 - 사용자: '전'이 어색해서 '이전'으로, 뜻 before, earlier
 - 초원 8번 줄 문장에 '이전'이 없어서 문장을 '사라지기 전에' → '사라지기 이전에'로 고침 (영어 줄은 그대로). 고친 문장은 picks 파일에 적어 둠 (도구가 고친 문장을 받게 함)
 - 한 단어는 한 단어장에만 들어가야 해서 숲부터 단어장을 한 칸씩 옮김: 235번 줄('이전 지도들에는 여기에…') = 이전 → 여기(here),
   104번 줄('여기가 내 지도에서 가장 외딴 곳이다') = 여기 → 곳(place, spot — 국립국어원 A등급, 새 단어)
 - '곳'에 place를 쓰려고 숲 단어장 놓다의 뜻을 'put, place' → 'put, set down'으로 (같은 단어장에 같은 뜻 조각이 두 번이면 보기가 같아짐)
 - 검증: 단어장 강조 450개 모두 찾음 · 로직 테스트 563 통과(2 건너뜀) · 검수 페이지 다시 올림
 - #6(전으로 되돌림)은 사용자 뜻을 잘못 알아들은 것 — 이번에 바로잡음

[2026-11-20] #6 단어 검수: 기록하다 → 전으로 되돌림
 - #4에서 '전'에 남기신 메모 '이전'을 '한 글자 전은 모호하다'로 읽고 '기록하다'로 바꿨는데, 사용자 확인 결과 '전 = 이전(before)이라는 뜻'이라는 설명이었음
   → 초원 단어장 8번 줄을 원래대로 '전'(before, earlier)으로 되돌림. '이전'은 숲부터 단어장 235번 줄에 따로 있음 (그대로)
 - 검수 페이지도 '전'으로 다시 올림 (같은 주소)
